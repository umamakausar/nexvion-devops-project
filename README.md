# AI-Powered E-Commerce DevOps Project

## Project Overview
This project demonstrates DevOps practices for deploying the Nexvion e-commerce website.

## Technologies Used
- AWS EC2
- Linux Ubuntu
- Git and GitHub
- Docker
- Nginx
- GitHub Actions

## Completed Tasks
- Set up the AWS EC2 environment.
- Installed Docker.
- Created a Dockerfile.
- Built and ran the Docker image.
- Deployed the website on EC2.
- Added Dockerfile and CI/CD workflow files to GitHub.
